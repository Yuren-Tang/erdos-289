## Proof architecture

The current manuscript spine is:

1. regular correction / exact-transfer calculus;
2. witness semantics and support reflection (`compose before reflect`);
3. target centering and compact quotient resolution;
4. the intrinsic binary/ternary component profile;
5. a fibrewise affine response `AFF2`;
6. a centered final-image saturation response `SAT2`;
7. one-defect exactification;
8. projection to Erdős Problem 289.

A stronger finite-defect uniformity theorem is obtained afterwards by finite intersection of final subsets of `N`; it is not needed for the shortest proof of the original problem.

## Explicit non-dependencies

The shortest manuscript proof does not treat the following as root ontology:

- Fourier root localizers or Gaussian amplifiers;
- lcm bridges or complete-sequence seeds;
- Raw / Prefix / Tail as theorem-level objects;
- absolute signed-inverse rates such as `Q/log Q`, `Q/p`, or `Q^{-2}`;
- a common tail across distinct defect fibres;
- an independent ordinary exact-grade root.

These may occur below provider interfaces or as retained stronger/alternative mathematics.

The R07 sectionwise matched-image theorem is also **not** used to weaken the current E289 arithmetic provider: the application continues to use its established stronger full simple-fibre coverage.
