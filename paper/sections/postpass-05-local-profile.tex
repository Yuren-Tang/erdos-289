\section{The finite simple-factor channel and a uniform dense-restriction profile}
\label{sec:local-profile}

This section is entirely target-level.  It does not choose a WideStart witness and it does not choose a Haxell packing.  The local theorem is proved uniformly for \emph{every sufficiently dense restriction of the original deterministic row} $A_Q$ from Section~\ref{sec:signed-inverse}.

Fix a cyclic group $S$ of prime order $p$, a finite occurrence set $A$, and a map
\[
f:A\to S^\times.
\]
Define the cardinality-graded subset-sum support
\[
\Gamma_f=
\left\{
\left(\sum_{x\in O}f(x),|O|\right):
O\subseteq A,\ |O|\le p
\right\}
\subseteq S\times\mathbf N.
\tag{5.1}\label{eq:gamma-f}
\]
For an incoming grade interval $I$, the observable target support is
\[
\Gamma_f+(\{0\}\times I).
\]

\subsection{Diversity and redundancy}

Let
\[
B=\operatorname{im}f,
\qquad r=|B|.
\]
For $0\le h\le r$, the full finite occurrence-lift relation from $h$-element subsets of $B$ to $h$ distinct occurrences in $A$ is surjective: every value fibre is nonempty, and distinct values force distinct lifted occurrences.  Thus Theorem~\ref{thm:restricted-fold} applies without choosing a section $B\to A$.

Define
\[
I_D(p,r)=\{h:h(r-h)+1\ge p\}.
\]
If this set is nonempty and $a=\min I_D(p,r)$, then symmetry and unimodality give
\[
I_D(p,r)=[a,r-a]\cap\mathbf N,
\]
and
\[
a<\frac{2p}{r}+1.
\tag{5.2}\label{eq:rich-demand}
\]
Hence the diversity branch gives
\[
S\times[A_0+a,B_0+r-a]
\subseteq
\Gamma_f+(\{0\}\times[A_0,B_0]).
\tag{5.3}\label{eq:rich-rectangle}
\]

The redundancy branch uses no additive theorem.  Suppose some $c\in S^\times$ has at least $p-1$ preimages.  Work with the full finite solution set of $(p-1)$-element subsets of $f^{-1}(c)$.  Its $j$-element subobjects give
\[
(jc,j)\in\Gamma_f
\qquad(0\le j<p).
\]
Since $j\mapsto jc$ bijects $\{0,\ldots,p-1\}$ with $S$, convolution with $[A_0,B_0]$ gives the common horizontal interval
\[
S\times[A_0+p-1,B_0]
\subseteq
\Gamma_f+(\{0\}\times[A_0,B_0])
\tag{5.4}\label{eq:poor-rectangle}
\]
whenever the incoming width is at least $p-1$.

These are different physical constructions.  We identify them only at the common rectangle property \eqref{eq:rich-rectangle}/\eqref{eq:poor-rectangle}.

\subsection{Uniformity over every dense restriction}

Let $\kappa>0$ be the lower row constant from Proposition~\ref{prop:signed-inverse-capabilities}, let $\sigma>0$ be the WideStart survivor fraction from Proposition~\ref{prop:wide-start}, and let $\rho_P>0$ be the non-small Haxell fraction from Proposition~\ref{prop:haxell-quota}.  Fix once and for all
\[
0<\rho<\kappa\sigma\rho_P.
\tag{5.5}\label{eq:rho-choice}
\]
The choice uses theorem-level constants only; no WideStart witness or packing point exists yet.

For a late current $Q=p^e$, define
\[
\boxed{
\operatorname{Adm}_\rho(Q)=
\left\{
A\subseteq A_Q:
|A|\ge \rho\frac Q{\log Q}
\right\}.}
\tag{5.6}\label{eq:adm-universal}
\]
This finite family is defined from the original signed-inverse row $A_Q$ itself.  In particular it is independent of every future obstacle deletion and every future Haxell witness.

Let $A\in\operatorname{Adm}_\rho(Q)$ and restrict the simple-value map to $A$.  By \eqref{eq:fibre-bound}, if
\[
M=\max_s|f^{-1}(s)|,
\]
then $M\le Q/p$.  Since
\[
|A|\le |\operatorname{im}f|M,
\]
we obtain
\[
r=|\operatorname{im}f|
\gg_\rho \frac p{\log Q}.
\tag{5.7}\label{eq:image-lower}
\]

If $I_D(p,r)$ is nonempty, \eqref{eq:rich-demand} and \eqref{eq:image-lower} give
\[
a(A)=O_\rho(\log Q).
\tag{5.8}\label{eq:rich-demand-log}
\]
If $I_D(p,r)$ is empty, then $r^2<4p$.  Combining this with \eqref{eq:image-lower} gives
\[
p=O_\rho((\log Q)^2).
\tag{5.9}\label{eq:poor-p-bound}
\]
Moreover some nonzero simple value has fibre size at least
\[
\frac{|A|}{r}
\gg_\rho\frac{Q}{\sqrt p\,\log Q}.
\tag{5.10}\label{eq:heavy-fibre}
\]
For a composite current $Q=p^e$, $e\ge2$, this lower bound is uniformly eventually larger than $p-1$.  Indeed, after division by $p$ the relevant ratio is
\[
\frac{Q}{p^{3/2}\log Q}
=
\frac{p^{e-3/2}}{e\log p}.
\tag{5.11}\label{eq:heavy-ratio}
\]
If $p\to\infty$, its smallest exponent occurs at $e=2$ and gives
\[
\frac{\sqrt p}{2\log p}\longrightarrow\infty.
\]
If $p$ remains bounded while $Q=p^e\to\infty$, then $e\to\infty$ and \eqref{eq:heavy-ratio} grows exponentially.  Thus one late threshold works for every composite current.  The redundancy rectangle \eqref{eq:poor-rectangle} therefore applies, with demand
\[
p-1=O_\rho((\log Q)^2)
\]
by \eqref{eq:poor-p-bound}.

For a prime current $Q=q$, the exact fibre capacity is $Q/p=1$, hence the simple-value map is injective and the poor branch is impossible.  Thus
\[
r=|A|\gg_\rho q/\log q,
\qquad
a(A)=O_\rho(\log q).
\tag{5.12}\label{eq:prime-rich}
\]

\subsection{Canonical extrema}

Choose a late threshold $Q_{\mathrm{prof}}$ beyond which all preceding estimates hold, and from now on define the profile only on currents of rank at least $Q_{\mathrm{prof}}$.

For $A\in\operatorname{Adm}_\rho(Q)$ define its route demand
\[
\delta(Q,A)=
\begin{cases}
a(A),&\text{in the diversity branch},\\
p-1,&\text{in the redundancy branch}.
\end{cases}
\]
Set
\[
\boxed{
d_\rho(Q)=
\max_{A\in\operatorname{Adm}_\rho(Q)}\delta(Q,A).}
\tag{5.13}\label{eq:common-demand}
\]
The previous bounds give
\[
d_\rho(Q)=O_\rho((\log Q)^2)
\tag{5.14}\label{eq:d-composite}
\]
for every late current, and
\[
d_\rho(q)=O_\rho(\log q)
\tag{5.15}\label{eq:d-prime}
\]
for prime currents.

Only after $d_\rho(q)$ is fixed do we define the prime mint
\[
\boxed{
m_\rho(q)=
\min_{A\in\operatorname{Adm}_\rho(q)}
\bigl(r_A-a(A)-d_\rho(q)\bigr).}
\tag{5.16}\label{eq:common-mint}
\]
By \eqref{eq:prime-rich}--\eqref{eq:d-prime},
\[
m_\rho(q)\gg_\rho q/\log q.
\tag{5.17}\label{eq:mint-prime}
\]

\begin{theorem}[Uniform local profile]\label{thm:uniform-profile}
For every late current and every $A\in\operatorname{Adm}_\rho(Q)$, the same profile applies to the target relation determined by $A$.

If $Q$ is composite and the incoming interval is $[A_0,B_0]$ of width at least $d_\rho(Q)$, then
\[
S_Q\times[A_0+d_\rho(Q),B_0]
\]
is contained in the observable response support.

If $Q=q$ is prime, then
\[
S_q\times
[A_0+d_\rho(q),\,B_0+d_\rho(q)+m_\rho(q)]
\]
is contained in the observable response support.
\end{theorem}

The theorem is stronger than packing-independence: it is uniform under \emph{every} sufficiently dense restriction of the original arithmetic row.  Physical independence will enter only when the finite horizon is realized in Section~\ref{sec:finite-realization}.
